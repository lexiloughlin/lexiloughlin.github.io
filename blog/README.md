# Blog folder

Every `.md` file in this folder becomes a post on the About me page.

1. Copy `_template.md` (files starting with `_` are hidden from the site).
2. Name the copy with the date first, like `2026-10-22-my-first-post.md`.
3. Fill in the title, write the post, and commit. It shows up on the site within a minute or two.

Set `draft: true` to hide a post until it's ready.
